# Studio OS Experiment Pilot

This standalone module uses newly created demo content. Do not import Studio OS
private memory, recordings, account caches, or customer data.

Flagsmith is the live source of assignments and experiment results. Rehearsal
data must remain visibly synthetic. Local beta-binomial estimates are not
Flagsmith analysis or evidence of real audience impact. Do not call template
planning a model invocation.

The MCP agent can propose and inspect; it cannot approve on behalf of a human.
Launch, development rollout and rollback require the current plan hash and the
browser approval action. Never make production changes or remove these gates.

Keep management keys server-side and out of logs, exports and commits. Do not
run arbitrary shell commands from API or MCP input. Run meaningful focused
tests for approval, evidence and integration behavior before shipping.
